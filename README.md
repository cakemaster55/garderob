# Гардероб

Личный гардероб в телефоне: фотографируешь вещи, фон убирается сам, вещи раскладываются
по категориям. Дальше приложение считает, что ты правда носишь, а что лежит без дела, —
чтобы было понятно, что продать, отдать, выкинуть и чего не хватает.

**Открыть:** https://cakemaster55.github.io/garderob/

Это веб-приложение (PWA): ставится на экран «Домой» айфона и работает без интернета.
Фото обрабатываются на самом телефоне и никуда не отправляются, сервера у приложения нет.

## Как поставить на айфон

1. Открой ссылку выше в Safari.
2. Нажми «Поделиться» → «На экран „Домой“».
3. Дальше запускай приложение со значка. Вещи добавляй уже там: у значка своя память,
   отдельная от Safari.

Первое добавление фото скачивает модели (около 26 МБ) — один раз, потом всё работает офлайн.

## Что умеет

- **Добавление вещей.** Камера или сразу пачка фото из галереи. Обычные снимки: вещь на полу
  или кровати, снятая сверху целиком. Фон вырезается, картинка обрезается по вещи.
- **Категории сами.** Верх, низ, платья, верхняя одежда, обувь, аксессуары — плюс тип
  (футболка, джинсы, кроссовки…) и основной цвет. Всё можно поправить одним нажатием.
- **Учёт носки.** Кнопка «Что на мне сегодня» — нажимаешь на вещи, которые надел.
  На каждой вещи бирка с числом выходов. Вещи, которые давно не надевал, бледнеют прямо в сетке.
- **Разбор.** Какую долю гардероба ты носишь, на чём он держится, что лежит без дела
  и сколько это стоило, цена одного выхода, перекосы по категориям и цветам.
  Каждой вещи можно вынести решение: оставить, продать, отдать, выкинуть. Есть список «Купить».
- **Образы.** Конструктор: внизу лента инвентаря, вещи перетаскиваются пальцем на полотно,
  двигаются, меняют размер двумя пальцами, меняются слоями. «Надел сегодня» на образе
  отмечает сразу все его вещи.
- **Резервная копия.** Один файл со всеми вещами, фото и историей — сохранить в «Файлы» / iCloud
  и восстановить на другом телефоне.

## Советы по фото

- Одна вещь на фото, целиком в кадре.
- Фон ровный и другого цвета, чем вещь.
- Если фон пёстрый и вырезалось плохо — в карточке вещи есть «Вырезать точнее»
  (медленнее, в первый раз скачивает ещё 86 МБ).

## Как устроено

Чистые HTML, CSS и JavaScript без сборки — репозиторий раздаётся GitHub Pages как есть.

| Что | Где |
| --- | --- |
| Интерфейс | `index.html`, `css/app.css`, `js/app.js`, `js/views/*` |
| Данные на устройстве (IndexedDB) | `js/db.js`, `js/store.js` |
| Обработка фото | `js/pipeline.js` |
| Нейросети (в отдельном потоке, ONNX Runtime Web) | `js/ml-worker.js`, `models/`, `vendor/ort/` |
| Офлайн | `sw.js`, `manifest.webmanifest` |
| Как обучена модель категорий | `tools/train/` |

Запустить у себя: любой статический сервер в корне репозитория, например `npx serve`.

Сторонние компоненты и их лицензии — в [THIRD_PARTY.md](THIRD_PARTY.md).

# Как обучена модель категорий

`models/clothes.onnx` — MobileNetV3-Large (веса ImageNet из `timm`) с дополнительной
линейной «головой» на 10 типов одежды. Голова обучена на открытом наборе
[clothing-dataset-small](https://github.com/alexeygrigorev/clothing-dataset-small) (CC0):
это обычные любительские фото вещей на полу, кровати, вешалке.

Шаги (нужны `torch`, `timm`, `onnx`, `onnxruntime`, `onnxconverter-common`, `scikit-learn`, `opencv`):

1. `mkcut.py` — вырезает фон у всех фото той же моделью (`u2netp`), что и приложение,
   и кладёт вещь на белый квадрат. Модель категорий учится на том же виде картинок,
   который потом получает в телефоне.
2. `train.py dscut` — считает признаки MobileNetV3 (с лёгкой аугментацией).
3. `fit.py` — логистическая регрессия поверх признаков.
   На отложенной выборке: 91% по типу вещи, 96% по категории (верх / низ / обувь / …).
4. `export.py` — собирает сеть и голову в один ONNX с двумя выходами
   (`clothes` — 10 типов, `imagenet` — 1000 классов для аксессуаров и уточнений)
   и переводит веса в float16 (11 МБ).

Точная модель вырезания `models/isnet-fp16.onnx.part*` — это ISNet (general use)
из релизов [rembg](https://github.com/danielgatis/rembg), у которой оставлен один выход,
а веса переведены в float16. Файл разрезан на три части по 30 МБ.
